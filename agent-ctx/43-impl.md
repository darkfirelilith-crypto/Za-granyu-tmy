### src/lib/vtm-chronicle-md.ts
- `buildBloodThreadMarkdown(data)`: единая «Кровавая нить» = вкладка «Хроника» в Markdown.
  Источники: notes.entries (title==="Новая охота" → hunt 🌙, иначе note 🖋), diablerie.entries
  (⚷ + теги ↑СК / +пятно / воля N/D), xpLog (✦). Локальный терпимый парсер дат
  `parseRuDateMsLocal` (копия логики вкладки: ISO / «21.09.2026[, HH:mm]» / «21 сент., 13:35»),
  сортировка как в вкладке (свежие сверху, неразобранные — на месте источника).
  Структура: `# 🩸 Кровавая нить — {имя}` + identity-цитата (клан/секта/поколение/хроника) +
  контекст «СК N · Голод N · Человечность N/10 · пятен N · ночей N» + строка счётчиков
  (ночей/записей/церемоний/строк опыта) + нить (`## {emoji} {title}`, `*{дата} · {вид}*`,
  опц. строка тегов, полный текст; охоты — целиком) + разделители, приложение-черновик
  (как в buildChronicleMarkdown) и футер. СК считается честно: max(bloodPotencyByGeneration, bpOverride).
- `bloodThreadFileName(name)` → «Кровавая-нить-{имя}-{ДД-ММ-ГГГГ}.md».

## Риски / заметки
- `display` у подписи резонанса в flex-контейнере вычисляется как block (blockification) — это норма CSS;
  важно, что `display:none` из `.hidden` побеждён.
- В экспорте нити XP-записи идут с общим заголовком «Журнал опыта» (как в ленте вкладки) — осознанно.
- Парсер дат «21 сент.» привязывает месяц к текущему году (как и во вкладке) — записи старше года
  в конце декабря могут сортироваться неточно (унаследованное поведение).
